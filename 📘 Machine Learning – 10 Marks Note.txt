1. Introduction to Machine Learning (10 Marks)

Machine Learning ek AI ka subset hai jisme computer ko data se seekhne aur apni performance improve karne ki capability di jaati hai bina explicitly program likhe.

Matlab system khud hi apne past experience se learn karke naye predictions kar sakta hai.

Key Features:

Data se pattern identify karta hai.

More data = better accuracy.

Human intervention kam ho jaata hai.

Structured aur unstructured dono data pe kaam kar sakta hai.

Complex aur uncertain environment mein bhi kaam karta hai.

Applications:

Email spam detection.

Fraud detection.

Netflix recommendations.

Healthcare disease prediction.

Self-driving cars.

Types of ML:

Supervised Learning – labeled data use karta hai.

Unsupervised Learning – unlabeled data use karta hai.

Reinforcement Learning – trial and error se seekhta hai.

Challenges:

Large dataset ki zarurat.

Overfitting / underfitting ka issue.

Computationally expensive.

👉 Conclusion: ML is the base of intelligent systems jo modern world mein automation aur decision making ko easy banata hai.

🔹 Python Example Code:

# Simple Machine Learning Example: Predict house price
from sklearn.linear_model import LinearRegression
import numpy as np

# Data: square_feet and price
X = np.array([[1000], [1500], [2000], [2500]])
y = np.array([200000, 300000, 400000, 500000])

model = LinearRegression()
model.fit(X, y)

# Predict price of 1800 sq.ft house
print("Predicted Price:", model.predict([[1800]]))

2. Machine Learning Techniques (10 Marks)

Techniques of ML:

Classification:

Output categorical hota hai (Yes/No).

Example: Email spam or ham.

Algorithms: Logistic Regression, Decision Tree.

Regression:

Output continuous hota hai (numbers).

Example: Predicting salary, house price.

Algorithms: Linear Regression, Polynomial Regression.

Clustering:

Data ko groups mein divide karta hai without labels.

Example: Customer segmentation.

Outlier Detection:

Abnormal data points identify karta hai.

Example: Fraud detection in transactions.

Other Methods:

Dimensionality reduction (PCA).

Ensemble learning (Random Forest).

👉 Techniques ka use real-world prediction aur analysis ke liye hota hai.

🔹 Python Example Code:

# Classification Example: Iris Dataset
from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split
from sklearn.tree import DecisionTreeClassifier

iris = load_iris()
X, y = iris.data, iris.target
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3)

model = DecisionTreeClassifier()
model.fit(X_train, y_train)

print("Accuracy:", model.score(X_test, y_test))

4. Supervised vs Unsupervised Learning (10 Marks)

Supervised Learning:

Input + output labels hote hain.

Example: Salary prediction.

Unsupervised Learning:

Sirf inputs hote hain, output nahi.

Example: Grouping customers.

Comparison:

Feature	Supervised	Unsupervised
Data	Labeled	Unlabeled
Goal	Prediction	Pattern discovery
Algorithms	Regression, SVM	K-means, PCA

👉 Supervised prediction ke liye, unsupervised pattern discovery ke liye use hota hai.

🔹 Python Example Code:

# Supervised: Linear Regression
from sklearn.linear_model import LinearRegression
import numpy as np

X = np.array([[1], [2], [3], [4]])
y = np.array([2, 4, 6, 8])

model = LinearRegression()
model.fit(X, y)
print("Prediction for 5:", model.predict([[5]]))

# Unsupervised: K-means
from sklearn.cluster import KMeans
import matplotlib.pyplot as plt

data = np.array([[1,2],[1,4],[1,0],[10,2],[10,4],[10,0]])
kmeans = KMeans(n_clusters=2).fit(data)

plt.scatter(data[:,0], data[:,1], c=kmeans.labels_)
plt.show()

5. Universal Approximators (10 Marks)

Neural Networks universal approximators hote hain.

Matlab ye kisi bhi continuous function ko approximate kar sakte hain.

Theorem:

Ek feedforward NN with one hidden layer aur sufficient neurons kisi bhi function ko approximate kar sakta hai.

Applications:

Image recognition.

NLP.

Stock prediction.

👉 Ye property hi neural networks ko powerful banati hai.

🔹 Python Example Code (NN using Keras):

model.fit(X, y, epochs=200, verbose=0)

🔹 Python Example Code:

# Backpropagation example with Keras NN
from tensorflow.keras.models import Sequential
from tensorflow.keras.layers import Dense
import numpy as np

X = np.array([[0,0],[0,1],[1,0],[1,1]])  # XOR problem
y = np.array([[0],[1],[1],[0]])

model = Sequential()
model.add(Dense(4, input_dim=2, activation='relu'))
model.add(Dense(1, activation='sigmoid'))

model.compile(optimizer='adam', loss='binary_crossentropy', metrics=['accuracy'])
model.fit(X, y, epochs=500, verbose=0)

print("Prediction:", model.predict(X))

7. Error Surface Learning (10 Marks)

Error surface ek graphical representation hai jisme error vs weights plot hota hai.

Neural network ka goal hota hai minimum error (global minimum) tak pohchna.

Concepts:

Gradient Descent algorithm error surface ke slope ko follow karta hai.

Kabhi kabhi local minima aur saddle points problem create karte hain.

Challenges:

Local minima.

Vanishing gradients.

Solutions:

Momentum, RMSProp, Adam optimizer use karna.

Proper initialization of weights.

👉 Error surface ko samajhne se training process clear hota hai aur optimization algorithms ka role samajh aata hai.

🔹 Python Example Code (Error surface visualization):

import numpy as np
import matplotlib.pyplot as plt

# Error function: y = (w-3)^2 + 2
w = np.linspace(-5, 10, 200)
error = (w - 3)**2 + 2

plt.plot(w, error)
plt.xlabel("Weights")
plt.ylabel("Error")
plt.title("Error Surface")
plt.show()

# Logistic Regression Classification Example
from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LogisticRegression

iris = load_iris()
X_train, X_test, y_train, y_test = train_test_split(iris.data, iris.target, test_size=0.3)

model = LogisticRegression(max_iter=200)
model.fit(X_train, y_train)

print("Accuracy:", model.score(X_test, y_test))

10. Clustering (10 Marks)

Clustering ek unsupervised learning method hai jo data ko groups (clusters) mein divide karta hai.

Types:

K-means Clustering:

Data ko k clusters mein divide karta hai.

Centroids update hote hain har iteration mein.

Hierarchical Clustering:

Tree-like structure (dendrogram) banata hai.

Agglomerative (bottom-up) & Divisive (top-down).

Density-based (DBSCAN):

Clusters ko data density ke basis pe banata hai.

Noise points ko handle karta hai.

Applications:

Market segmentation.

Document clustering.

Image compression.

👉 Clustering unlabeled data ko organize karne ke liye powerful hai.

🔹 Python Example Code:

# K-means Clustering Example
from sklearn.cluster import KMeans
import numpy as np
import matplotlib.pyplot as plt

data = np.array([[1,2],[1,4],[1,0],[10,2],[10,4],[10,0]])
kmeans = KMeans(n_clusters=2, random_state=0).fit(data)

plt.scatter(data[:,0], data[:,1], c=kmeans.labels_)
plt.scatter(kmeans.cluster_centers_[:,0], kmeans.cluster_centers_[:,1], color='red')
plt.show()

11. Outlier Detection (10 Marks)

Outliers wo data points hote hain jo normal data se bahut zyada different hote hain.

Ye kabhi kabhi measurement error hote hain ya real anomalies.

Methods:

Statistical:

Z-score method.

IQR (Interquartile Range).

Machine Learning Based:

Isolation Forest.

One-Class SVM.

Local Outlier Factor (LOF).

Applications:

Fraud detection.

Fault detection.

Intrusion detection in networks.

👉 Outliers detect karna zaruri hai kyunki wo model ko mislead kar dete hain.

🔹 Python Example Code:

# Outlier Detection with Isolation Forest
from sklearn.ensemble import IsolationForest
import numpy as np

X = np.array([[1],[2],[2],[3],[100]])  # 100 is outlier
clf = IsolationForest(contamination=0.2)
clf.fit(X)

print("Outlier Predictions:", clf.predict(X))  # -1 = outlier, 1 = normal1
