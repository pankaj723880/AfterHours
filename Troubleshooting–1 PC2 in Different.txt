Troubleshooting–1: PC2 in Different IP Network

Observed Problem:

PC0 successfully pings PC1

Ping from PC0 to PC2 fails (Request timed out)

Fault Created:

PC2 configured with IP 192.168.2.3 while PC0 and PC1 are in 192.168.1.x

Fault Isolation:

Physical connections: OK

Link lights: Green

IP configuration checked on all PCs

Network mismatch found on PC2

Fix Applied:

Changed PC2 IP to 192.168.1.3

Subnet Mask: 255.255.255.0

Verification:

Ping from PC0 to PC2 successful

Troubleshooting–2: Incorrect Subnet Mask on PC1

Observed Problem:

PC1 unable to communicate with PC0 and PC2

Fault Created:

Subnet mask on PC1 set to 255.255.0.0

Fault Isolation:

IP address correct

Subnet mask mismatch identified during IP configuration check

Fix Applied:

Corrected subnet mask on PC1 to 255.255.255.0

Verification:

Successful ping between all PCs

Troubleshooting–3: Switch Port Fa0/3 Disabled (PC2)

Observed Problem:

PC2 shows no network connectivity

Ping to PC2 fails

Fault Created:

Switch port connected to PC2 (Fa0/3) was administratively disabled

Fault Isolation:

Physical cable connected properly

Switch port status checked

Fa0/3 found in shutdown state

Fix Applied:

Enabled switch port Fa0/3

Verification:

Link light turned green

PC2 reachable via ping

Troubleshooting–4: Duplicate IP Address Conflict Between PC0 and PC1

Observed Problem:

Network unstable

Ping shows packet loss

Fault Created:

PC0 and PC1 assigned same IP address 192.168.1.1

Fault Isolation:

IP conflict detected during IP configuration

ARP-related communication issue observed

Fix Applied:

Assigned unique IPs:

PC0 → 192.168.1.1

PC1 → 192.168.1.2

Verification:

Stable communication restored

Ping successful

Troubleshooting–5: Wrong Cable Type Between PC0 and Switch

Observed Problem:

No communication from PC0

Link indicator red

Fault Created:

Cross-over cable used instead of straight-through cable

Fault Isolation:

Physical layer inspection

Incorrect cable type identified

Fix Applied:

Replaced cable with Copper Straight-Through Cable

Verification:

Link light turned green

PC0 successfully pings PC1 and PC2
